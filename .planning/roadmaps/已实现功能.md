## 一、文档接入与解析（Markdown 结构感知）

> 标准（非 Markdown）RAG 竖井已全退役（迁移 031），系统现仅保留 Markdown 结构感知 RAG。

- **结构化切分** — `MarkdownStructureIngestionService`：按 H1–H3 切 parent（整段 section），parent 内再切段落级 child。
- **表格双表示** — 检索用逐行线性化、返回用原始 markdown。
- **图片理解** — `MdImageUnderstandingService`，可在 Noop / DashScope（Qwen-VL）间切换。⚠️ 默认 Noop，**不支持真正的图片信息检索**（仅占位，勿对外称"视觉检索"）。
- **分块持久化** — `md_parent_chunk` / `md_child_chunk` / `md_document_asset`（PostgreSQL）。
- **向量入库** — `MdVectorStoreService`：child 的 `embed_text` 经 `EmbeddingModel` 入 Milvus `md_kb_chunks`（1536 维 COSINE）。
- **原始文件存储** — `.md` 原文存 MinIO（`MinioDocumentObjectStorageService`）。
- **异步入库** — `MdDocumentIngestionWorker`，JDK 21 虚拟线程（`ingestionExecutor`）。
- **状态机** — `PENDING → PROCESSING → READY / FAILED`。

## 二、混合检索（MD Hybrid Search）

- **向量召回** — `MdVectorSearchService`，`md_kb_chunks` 相似度检索。
- **关键词召回（BM25）** — `MdKeywordSearchService`，`md_child_chunk` 上的关键词检索，已升级真正 BM25（VectorChord-bm25 + jieba，adr-013）。`db/manual/md-bm25-build.sql` 已执行跑通：`tokenizer_catalog` 三表与 `md_model` 词表已生成，运行时实际走 BM25（不再降级 pg_trgm）。
- **RRF 融合** — `MdHybridSearchService`，向量 + 关键词并行后按排名融合（child 粒度，融合阶段不去重）。
- **重排** — `RerankService`，DashScope `gte-rerank`，child 粒度精排，降级兜底返回原始 RRF。
- **查询改写 / HyDE** — `QueryRewriteService` / `HydeService`。
- **父块扩展（small-to-big）** — `MdParentExpansionService`：topK child 按 `parentId` 折叠去重，回查整段 parent 正文 + 多窗节选交给 LLM。

## 三、问答（QA）

- **标准 MD 问答** — `MdQnAServiceImpl`：混合检索 → rerank → parent expansion → prompt → LLM。
- **Agentic 问答** — `MdAgenticQnAServiceImpl`：Spring AI Alibaba `ReactAgent`，双工具 `searchKnowledgeBase`（搜 child）+ `readFullSection`（按需展开 parent）。
- **Token 预算** — `AgenticTokenBudgetService`。
- **流式输出** — `MdQnAController` 暴露 SSE 端点（`text/event-stream`）；前端 `md-pages.js` 已消费流式。
- **会话管理** — `qa_sessions` / `qa_messages`（PostgreSQL）+ Redis 对话历史（TTL 24h）；会话列表 / 历史消息 / 改标题 / 软删除接口齐全（`QaChatSessionService`）。

## 四、商城客服助手 / 投诉工作流（独立于知识库检索）

- **客服助手** — `CustomerAssistantService`，自有 `ReactAgent`，不依赖 KB 检索。
- **两层意图路由** — `DomainRouterService`（Tier-1 分域）+ `DomainHandler`（Tier-2 选工具，含 `AfterSalesDomainHandler` / `ComplaintDomainHandler`）。⚠️ Phase 0-3 全实现、76 单测通过，但 kill-switch `routing-enabled` 默认 false、评估集为模板、影子数据为空，**尚未上线**。
- **投诉升级 StateGraph** — `ComplaintWorkflow` + planner / executor / replanner / responsibility inference 全套。
- **售后 HITL** — `ReviewRequestService`（人工介入审核）。
- **攻击守卫** — `AttackGuardService`（⚠️ 仅在客服链路，KB 问答链路未接）。
- **投诉截止调度** — `ComplaintDeadlineScheduler`（`@Scheduled`）。

## 六、在线可观测性（LangFuse Tracing）

- **链路** — Micrometer Observation → OpenTelemetry SDK → OTLP/HTTP → 自部署 LangFuse（ADR-015）。
- **覆盖** — service 根 span（`kb.qa.ask*` / `kb.ingest.*`）+ LLM span + tool span + graph/node 子树 + 检索四段 span；脱敏 + 截断；业务属性走 thread-local 不经 baggage。
- **总开关** — `enterprise.kb.tracing.enabled`（默认 false，关闭零开销）。
- ⚠️ 代码已落地、全模块编译通过，但 **span 树渲染 / event→attribute 映射 / 跨线程传播均未起栈实测**。

## 七、多模型提供商

- **运行时切换** — `ModelProviderResolver` 按请求 `modelProvider` 注入对应 `@Qualifier` bean。
- **Chat** — `dashscopeChatClient` / `llamaCppChatClient`（llama.cpp 本地模型，OpenAI 兼容）。默认 `LLAMA_CPP`。
- **Embedding** — `dashscopeEmbeddingModel`（经 `BeanFactoryPostProcessor` 标 `@Primary`）。默认 `DASHSCOPE`。
- MiniMax 已退役（bean / 依赖 / 配置 / Key 全移除）。

## 八、认证与权限

- **JWT 认证** — 登录 / 注册 / Token 刷新（`kb-auth`），BCrypt 密码加密，JWT 密钥启动时校验（`JwtServiceImpl @PostConstruct`，≥ 32 字节）。
- **空间级 RBAC** — `@PreAuthorize("hasPermission(#spaceId, 'SPACE', 'VIEWER')")`，`SpacePermissionEvaluator` 解析 OWNER/EDITOR/VIEWER（`user_space_roles`），在 `AppConfig` 装配避免循环依赖。

## 九、基础设施

- **存储** — PostgreSQL 16（关系数据）/ Milvus 2.4（向量）/ Redis 7（会话缓存）/ MinIO（对象存储）。
- **数据库迁移** — Liquibase，编号 001–033（`db.changelog-master.xml`）。
- **部署** — `docker compose --env-file .env up -d`，应用端口 8081，Actuator `/health` 存活检查。
- **跨模块装配** — `AppConfig` 手工构造会产生循环依赖的 bean（`AuthService` / `MethodSecurityExpressionHandler` / `ingestionExecutor` / `milvusClient`）。
